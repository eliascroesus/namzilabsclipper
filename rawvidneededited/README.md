# Raw videos that need editing

Raw footage to be cut into edits: vlogs, phone clips, screen recordings, long YouTube videos. It's for a new page of the clipper; what that page does is still to be decided.

## How to upload

1. Open this folder on GitHub: `rawvidneededited/` on the `claude/laughing-wozniak-zg8a1n` branch.
2. **Add file → Upload files**, drag the videos in, then **Commit changes**.
3. Tell Claude they're in.

- MP4 or MOV, the original file at the best quality you have.
- The browser takes files up to 25 MB each. For anything bigger, compress it or share a Google Drive link instead.
- No special names needed. If a video goes with a song or an edit in `inspirationedit/`, say so in the commit message.

## Make the repo private first

This repo is public, so anything uploaded here can be downloaded by anyone. Switch it to private before uploading footage you don't want public: **Settings → General → Danger Zone → Change repository visibility**.
