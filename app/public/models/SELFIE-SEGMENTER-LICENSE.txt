selfie-segmenter.tflite

MediaPipe's selfie segmenter (the square 256 x 256 model, float16), which tells
a person from the background in a picture
(https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/latest/selfie_segmenter.tflite;
model card: https://storage.googleapis.com/mediapipe-assets/Model%20Card%20MediaPipe%20Selfie%20Segmentation.pdf).
It runs in the page on MediaPipe's vision task runtime (@mediapipe/tasks-vision, Apache 2.0),
to set captions behind the person talking.
